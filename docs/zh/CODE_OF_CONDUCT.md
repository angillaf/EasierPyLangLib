# 贡献者公约行为准则

## 我们的承诺

作为成员、贡献者和领导者，我们承诺让参与本社区成为每个人都能安全、无骚扰地体验，不论其年龄、体型、可见或不可见的残障、民族、性征、性别认同与表达、经验水平、教育程度、社会经济状态、国籍、个人外貌、种族、宗教或性取向如何。

我们承诺以开放、友善、多元、包容和健康的方式参与和互动，促进一个积极的社区环境。

## 我们的标准

有助于营造积极社区环境的行为示例包括：

- 对他人表现出同理心和善意
- 尊重不同意见、观点和经验
- 给予并优雅地接受建设性的反馈
- 对自己造成的错误承担责任并道歉，并从中学习
- 关注对整个社区而不仅仅是个体有益的事情

不可接受的行为示例包括：

- 使用带有性暗示或性相关的语言或图像，以及任何形式的性关注或骚扰
-  trolling、侮辱性或贬损性的评论，以及人身或政治攻击
- 公开或私下骚扰
- 未经明确许可发布他人的私人信息，例如地址或电子邮件地址
- 其他在专业环境中可合理视为不恰当的行为

## 执行责任

社区领导者负责澄清和执行我们的行为标准，并在认为任何行为不当、具有威胁性、冒犯性或有害时，采取适当且公平的纠正措施。

社区领导者有权利和责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、wiki 编辑、问题和其他贡献，并在适当时说明审核决定的理由。

## 适用范围

本行为准则适用于所有社区空间，也适用于当个人在公共空间正式代表社区时。

代表社区的例子包括使用官方电子邮件地址、通过官方社交媒体账号发帖，或在在线或线下活动中担任指定代表。

## 执行

如果发生辱骂、骚扰或其他不可接受的行为，可向负责执行的社区领导者报告，联系方式为：

- @yFish26
- yufish26@outlook.com

所有投诉都会被及时、公平地审查和调查。

所有社区领导者都有义务尊重和保护事件报告人的隐私与安全。

## 执行指南

社区领导者在决定任何违反本行为准则的行动时，将参考以下“社区影响指南”：

### 1. 更正

社区影响：使用不当语言或其他被视为不专业、不受欢迎的行为。

后果：社区领导者发出私人书面警告，说明违规性质及其不当之处，并解释为什么该行为不合适。必要时可能要求公开道歉。

### 2. 警告

社区影响：通过单次事件或一连串行为造成的违规。

后果：对持续违规行为发出警告，并在指定期限内限制与相关人员的互动，包括避免在社区空间以及外部渠道（如社交媒体）进行不必要的联系。违反这些条款可能导致临时禁言或禁令。

### 3. 临时禁言

社区影响：严重违反社区标准，包括持续的不当行为。

后果：在指定期限内被禁止参与任何形式的互动或公开交流；在此期间不得与相关人员进行公开或私下交流，包括与执行者进行不必要的互动。违反规定可能导致永久禁言。

### 4. 永久禁言

社区影响：表现出一贯违反社区标准，包括持续不当行为、骚扰个人或对某类群体进行攻击或贬低。

后果：永久禁止在社区内进行任何公开互动。
